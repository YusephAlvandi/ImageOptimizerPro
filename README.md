Image Optimizer Pro

A smart batch image compression tool.

Built with Python, CustomTkinter, and Pillow. Works offline.


WHAT IT DOES

Compresses images in bulk while controlling quality. If a compressed image is going to end up larger than the original, the original size is kept. No waste of space is guaranteed.


COMPETITIVE ADVANTAGE

- Smart fallback; never replaces an image with a larger version
- Batch processing; optimize all the content of a folder simultaneously
- Adjustable quality slider with live preview of the compression level
- Works offline; your data won't leave your computer
- Built by a rigorous physicist


HOW TO RUN

pip install customtkinter pillow
python image_optimizer.py
